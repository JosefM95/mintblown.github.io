Werkzeugkasten 1

Java-Syntax · vollständige Grundlagen

Diese Übersicht erklärt die Syntaxregeln, die du zum Lesen und Ändern der Ballwurfspiel-Klasse brauchst. Java ist genau: Groß- und Kleinschreibung zählen; GLKugel und glKugel sind verschiedene Namen. Lies zuerst die kurze Regel und öffne das Beispiel, wenn du mehr sehen möchtest.

1 · Befehle, Semikolons und Codeblöcke

Ein einzelner Befehl, etwa eine Zuweisung oder ein Methodenaufruf, endet normalerweise mit ;. Bei einer if- oder Schleifenkopfzeile, die einen Codeblock öffnet, steht kein Semikolon. Auch vor dem Codeblock einer normalen Methode steht keines. Ein Codeblock beginnt mit { und endet mit }.

Beispiel · Wo gehört das Semikolon hin? 
double schrittweite = 1.0;
ball.verschiebe(schrittweite, 0, 0);

if (tastatur.links()) {
    ball.verschiebe(-1, 0, 0);
}

Die Variablenzuweisung und beide Methodenaufrufe sind Befehle und enden mit ;. Hinter der if-Bedingung und der schließenden Klammer steht keines.

2 · Klammern und Einrückung

Runde Klammern ( ) umschließen zum Beispiel Bedingungen und Methodenparameter. Geschweifte Klammern { } fassen mehrere Befehle zu einem Block zusammen. Eckige Klammern [ ] werden unter anderem für Arrays verwendet. Jede öffnende Klammer braucht den passenden Abschluss.

Einrückung ist keine Pflicht für den Java-Compiler, aber eine wichtige Lesehilfe. Sie zeigt, welche Befehle innerhalb eines Blocks stehen; verbindlich sind die geschweiften Klammern.

Beispiel · Welcher Code gehört zur Schleife? 
while (bedingung) {
    ersterBefehl();
    zweiterBefehl();
}
dritterBefehl();

Nur die ersten beiden Aufrufe stehen zwischen den geschweiften Klammern und gehören zum Schleifenkörper. Der letzte Befehl folgt nach der Schleife.

3 · Variablen: deklarieren, initialisieren und verwenden

Eine Variable hat einen Typ und einen Namen. Beim Deklarieren wird sie bekannt gemacht; beim Initialisieren erhält sie ihren ersten Wert. Eine lokale Variable muss initialisiert sein, bevor ihr Wert verwendet wird. Im selben lokalen Gültigkeitsbereich darf derselbe Name nicht noch einmal deklariert werden; in getrennten Methoden können gleiche Namen vorkommen. Für Einsteiger ist es am klarsten, Feld- und lokale Variablennamen nicht zu überdecken.

Beispiel · Was bedeuten die drei Zeilen? 
double schrittweite;
schrittweite = 1.0;
ball.verschiebe(schrittweite, 0, 0);

In der ersten Zeile wird schrittweite deklariert. Die zweite initialisiert die Variable. Erst danach wird ihr Wert im Methodenaufruf verwendet.

Beispiel · Welche Namen sind erlaubt und gut lesbar? 
double schrittweite = 1.0;
GLKugel zielscheibe;

int 2versuche = 3; // Ungültig: 2versuche beginnt mit einer Ziffer
GLQuader class; // Ungültig: class ist ein reserviertes Java-Wort

Ein Variablenname beginnt üblicherweise mit einem Buchstaben; Ziffern können danach vorkommen. Leerzeichen sind nicht erlaubt und reservierte Java-Schlüsselwörter wie class dürfen nicht als Namen verwendet werden. Java erlaubt weitere Startzeichen wie _ oder $, die in Unterrichtsbeispielen aber besser vermieden werden. Variablennamen beginnen meist klein, Klassennamen meist groß.

4 · Datentypen

Java besitzt primitive Datentypen für einzelne Werte:

  • Ganze Zahlen: byte, short, int, long.
  • Kommazahlen: float, double.
  • Wahrheitswerte: boolean mit den Werten true oder false.
  • Einzelne Zeichen: char, zum Beispiel das Leerzeichen in ' '.

Klassen sind selbst definierte oder bereitgestellte Referenztypen. String und GLOOP-Klassen wie GLKugel sind keine primitiven Datentypen. Werte unterschiedlicher Typen lassen sich nicht beliebig mischen; manchmal ist eine ausdrückliche Umwandlung nötig.

Beispiel · Zeichen oder Text? 
char taste = ' ';
String beschriftung = "Ball";

char steht in einfachen Anführungszeichen und enthält genau ein Zeichen. String steht in doppelten Anführungszeichen und kann eine Zeichenfolge enthalten.

5 · Operatoren

Operatoren und ihre Bedeutung
GruppeOperatorenBedeutung
Rechnen+ - * / %Addition (auch Textverknüpfung), Subtraktion, Multiplikation, Division und Rest einer Division.
Vergleichen< <= > >= == !=Kleiner, kleiner/gleich, größer, größer/gleich, gleich und ungleich. Das Ergebnis ist true oder false.
Logik&& || ! ^UND, ODER, NICHT und exklusives ODER bei Wahrheitswerten (genau einer ist wahr).
Beispiel · Zuweisen ist nicht Vergleichen 
int punkte = 3;              // Zuweisung: speichert 3
boolean genug = punkte >= 3; // Vergleich: ergibt true
boolean nichtGenug = !genug; // NICHT: kehrt true/false um

= speichert einen Wert. == fragt, ob zwei Werte gleich sind. Für Zahlen wird häufig == verglichen; für Text verwendet man in Java normalerweise equals.

Beispiel · Division, Rest und logische Operatoren 
int quotient = 7 / 2;            // 3: Ganzzahldivision
int rest = 7 % 2;                // 1: Rest
boolean erreichbar = links || rechts;
boolean nurEineTaste = links ^ rechts;

Wenn beide Operanden von / ganze Zahlen sind, ist auch das Ergebnis ganzzahlig; der Nachkommateil entfällt. % liefert den Rest. Bei Wahrheitswerten bedeutet || „mindestens eine wahr“ und ^ „genau eine wahr“. Bei Ganzzahlen wird ^ außerdem als bitweises exklusives ODER verwendet.

6 · Kontrollstrukturen: Reihenfolge, Wiederholung, Entscheidung

Ohne Kontrollstruktur führt Java Befehle der Reihe nach aus. Schleifen wiederholen Anweisungen. Verzweigungen entscheiden anhand einer Bedingung, welche Anweisungen ausgeführt werden. Eine Bedingung muss einen Wahrheitswert (boolean) ergeben.

Beispiel · Eine while-Schleife mit Zähler 
int zaehler = 0;
while (zaehler < 3) {
    zaehler = zaehler + 1;
}

Vor jedem Durchlauf prüft Java zaehler < 3. Der Wert steigt von 0 auf 1, 2 und 3. Bei 3 ist die Bedingung falsch und die Schleife endet. Eine Schleife braucht also eine erreichbare Endbedingung.

7 · if und if-else

Ein if-Block wird ausgeführt, wenn seine Bedingung wahr ist. Bei if-else wird genau einer der beiden Blöcke gewählt. Zwei einzelne if-Anweisungen bleiben unabhängig: Beide Blöcke können ausgeführt werden, wenn beide Bedingungen wahr sind.

Beispiel · Zwei Richtungen unabhängig prüfen 
if (tastatur.links()) {
    ball.verschiebe(-1, 0, 0);
}
if (tastatur.rechts()) {
    ball.verschiebe(1, 0, 0);
}

Java prüft beide Bedingungen. Das ist nicht dasselbe wie if (...) { ... } else { ... }, bei dem nur ein Zweig ausgewählt wird.

Beispiel · Eine von zwei Möglichkeiten wählen 
if (treffer) {
    tafel.setzeText("Treffer", 20);
} else {
    tafel.setzeText("Daneben", 20);
}

Ist treffer wahr, erscheint „Treffer“; sonst wird der else-Block ausgeführt.

8 · Kommentare

Kommentare erklären den Code für Menschen. Java führt ihren Inhalt nicht aus. Einzeilige Kommentare beginnen mit //; Bereichskommentare stehen zwischen /* und */.

Beispiel · Kommentare im Programm 
// Ball nach links bewegen
ball.verschiebe(-1, 0, 0);

/* Dieser Kommentar
   umfasst mehrere Zeilen. */

Werkzeugkasten 2

GLOOP 3.7: die Bausteine im Spiel

GLOOP stellt Klassen bereit, mit denen Java-Programme 3D-Szenen und Eingaben aufbauen. Im Startercode steht import GLOOP.*;, damit diese Klassen verwendet werden können. Für dieses Spiel brauchst du zuerst nur die folgende kleine Auswahl.

GLOOP-Begriffe aus dem Startercode
Name im CodeWas entsteht oder passiert?Woran erkennst du es?
GLKameraEine Kamera, durch die du die Szene siehst.Der Konstruktor new GLKamera() richtet das Ansichtsfenster ein.
GLLichtEine Lichtquelle für die 3D-Szene.new GLLicht() erzeugt das Licht.
GLHimmelEinen Himmel, hier mit einer Bilddatei als Textur.new GLHimmel("Himmel.jpg"); die Datei muss im Projekt verfügbar sein.
GLTastaturEin Objekt, das Tastaturzustände abfragt.links(), rechts(), oben(), unten() und istGedrueckt(' ') liefern boolean.
GLKugelEine Kugel mit Mittelpunkt und Radius.new GLKugel(x, y, z, radius).
GLQuaderEin Quader, dessen drei Kantenlängen getrennt festgelegt werden.new GLQuader(x, y, z, laengeX, laengeY, laengeZ); mit einer kleinen Y-Länge und großen X-/Z-Längen entsteht eine flache, breite Grundfläche.

Koordinaten lesen, ohne zu raten

GLOOP-Objekte werden mit X-, Y- und Z-Koordinaten positioniert. Bei der Kugel gibt new GLKugel(x, y, z, radius) erst den Mittelpunkt, dann den Radius an. verschiebe(dx, dy, dz) verändert die Position relativ: ball.verschiebe(-1, 0, 0) verschiebt um eins in negative X-Richtung; Y und Z bleiben dabei unverändert.

Die Kantenlängen des Quaders sind keine Koordinaten: Erst kommen seine drei Positionswerte, danach die Ausdehnung in X-, Y- und Z-Richtung. Für eine Grundfläche hilft ein gedanklicher Test: Welche Kante soll dünn sein, welche beiden sollen den Spielbereich abdecken?

Viele GLOOP-Klassen teilen Methoden ihrer Oberklasse GLObjekt, zum Beispiel gibX(), gibY() und gibZ() für die Mittelpunktkoordinaten, sowie setzePosition(...), setzeFarbe(...) und loesche(). Die genaue Liste hängt von der jeweiligen Klasse ab.

Warum steht manchmal ein Punkt zwischen zwei Namen?

ball.verschiebe(...) bedeutet: Rufe die Methode am Objekt ball auf. Sys.warte() ist dagegen ein statischer Aufruf der Hilfsklasse Sys; dafür wird kein Sys-Objekt erzeugt.

Die PDF-Übersicht beschreibt GLOOP 3.7 und ist ausdrücklich keine vollständige Klassenreferenz. Nutze sie als Nachschlagewerk, nicht als Liste, die du auswendig lernen musst.

Wiedererkennen

So passen Java und GLOOP zusammen

GLKugel ball;
ball = new GLKugel(0, 0, 0, 20);

if (tastatur.links()) {
    ball.verschiebe(-1, 0, 0);
}
Sys.warte();
  1. GLKugel ball; benennt eine Variable und ihren Typ.
  2. new GLKugel(...) erzeugt ein Kugelobjekt; die Zuweisung speichert die Referenz darauf in ball.
  3. tastatur.links() fragt die linke Pfeiltaste ab und liefert wahr oder falsch.
  4. Wenn sie gedrückt ist, wird verschiebe auf der Kugel ball ausgeführt.
  5. Sys.warte() hält kurz an, damit die wiederholten Spielschritte sichtbar und steuerbar bleiben.

Wichtig: Wenn BlueJ GLOOP als unbekannt meldet, fehlen wahrscheinlich Projekt oder Bibliothek aus der schulischen Einrichtung. Entferne den Import nicht, um die Meldung zu verstecken.
