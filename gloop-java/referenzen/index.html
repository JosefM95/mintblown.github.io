Werkzeugkasten 1

Java-Syntax: erst die Form, dann der Sinn

Java unterscheidet genau zwischen Groß- und Kleinschreibung. GLKugel und glKugel sind verschiedene Namen. Ein Befehl, der etwas tut, endet meistens mit einem Semikolon. Überschriften von Klassen, Methoden und Kontrollstrukturen enden dagegen nicht damit.

1 · Befehl oder Block?

ball.verschiebe(1, 0, 0);

if (tastatur.links()) {
    ball.verschiebe(-1, 0, 0);
}

Der Methodenaufruf ist ein einzelner Befehl und hat ein ;. Die if-Zeile eröffnet einen Block mit {; die schließende Klammer beendet den Block. An die Bedingung oder an eine schließende Blockklammer kommt hier kein Semikolon.

2 · Klammern gehören zusammen

( ) umschließen Bedingungen oder Parameter, { } umschließen Codeblöcke und [ ] werden zum Beispiel bei Arrays verwendet. Prüfe immer, ob jede öffnende Klammer ihren passenden Abschluss hat.

Einrückung ist keine Java-Pflicht, macht aber sichtbar, welche Befehle zu einer Bedingung oder Schleife gehören. Der eingerückte Block wird durch die geschweiften Klammern bestimmt.

3 · Name, Typ und Wert

double schrittweite = 1.0;
GLKugel ball = new GLKugel(0, 0, 0, 20);

double und GLKugel sind Typen; schrittweite und ball sind Variablennamen. = weist rechts stehenden Wert beziehungsweise das neu erzeugte Objekt links der Variablen zu. Namen sind innerhalb ihres Gültigkeitsbereichs eindeutig; derselbe Name kann in getrennten Methoden vorkommen.

4 · Werttypen und Objekt-Typen

Für dieses Projekt wichtig sind int für ganze Zahlen, double für Kommazahlen, boolean für true oder false und char für ein einzelnes Zeichen. Das Leerzeichen in ' ' ist ein solches Zeichen. String und GLOOP-Klassen wie GLKugel sind Objekttypen, keine primitiven Datentypen.

Lokale Variablen müssen einen Wert erhalten, bevor sie gelesen werden. Objektfelder bekommen zwar Java-Standardwerte, aber für Einsteiger ist eine klare, bewusste Initialisierung leichter zu verstehen.

Operatoren, die im Ballwurfspiel wirklich helfen

  • = weist einen Wert zu; == vergleicht zwei Werte auf Gleichheit.
  • <, >, <=, >= vergleichen Zahlen.
  • ! bedeutet „nicht“, && bedeutet „und“, || bedeutet „oder“.

Eine Bedingung muss am Ende true oder false ergeben. Zum Beispiel fragt !tastatur.istGedrueckt(' '): „Ist die Leertaste gerade nicht gedrückt?“

if: nur wenn die Bedingung stimmt

if (tastatur.links()) {
    ball.verschiebe(-1, 0, 0);
}

Der Block läuft nur, wenn die Bedingung true ist. Ohne else wird der folgende Code unabhängig davon weiter geprüft. Zwei einzelne if-Anweisungen sind also keine Entweder-oder-Auswahl.

while: wiederholen, solange wahr

while (!tastatur.istGedrueckt(' ')) {
    // wiederholt ausgeführter Spielschritt
}

Java prüft die Bedingung vor jedem Durchlauf. Ist sie false, wird der Block beendet. Im Starter läuft die Schleife weiter, solange die Leertaste nicht gedrückt ist.

Schleifen-Check: Welche Eingabe oder Wertänderung kann die Bedingung irgendwann falsch machen? Ohne erreichbares Ende kann eine Schleife weiterlaufen.

Was ist mit Kommentaren?

// kommentiert bis zum Zeilenende. /* ... */ umschließt einen Kommentarbereich. Kommentare erklären den Code für Menschen; Java führt sie nicht aus.

Werkzeugkasten 2

GLOOP 3.7: die Bausteine im Spiel

GLOOP stellt Klassen bereit, mit denen Java-Programme 3D-Szenen und Eingaben aufbauen. Im Startercode steht import GLOOP.*;, damit diese Klassen verwendet werden können. Für dieses Spiel brauchst du zuerst nur die folgende kleine Auswahl.

GLOOP-Begriffe aus dem Startercode
Name im CodeWas entsteht oder passiert?Woran erkennst du es?
GLKameraEine Kamera, durch die du die Szene siehst.Der Konstruktor new GLKamera() richtet das Ansichtsfenster ein.
GLLichtEine Lichtquelle für die 3D-Szene.new GLLicht() erzeugt das Licht.
GLHimmelEinen Himmel, hier mit einer Bilddatei als Textur.new GLHimmel("Himmel.jpg"); die Datei muss im Projekt verfügbar sein.

GLQuaderEin Quader, dessen drei Kantenlängen getrennt festgelegt werden.new GLQuader(x, y, z, laengeX, laengeY, laengeZ); mit einer kleinen Y-Länge und großen X-/Z-Längen entsteht eine flache, breite Grundfläche.

Koordinaten lesen, ohne zu raten

GLOOP-Objekte werden mit X-, Y- und Z-Koordinaten positioniert. Bei der Kugel gibt new GLKugel(x, y, z, radius) erst den Mittelpunkt, dann den Radius an. verschiebe(dx, dy, dz) verändert die Position relativ: ball.verschiebe(-1, 0, 0) verschiebt um eins in negative X-Richtung; Y und Z bleiben dabei unverändert.

Die Kantenlängen des Quaders sind keine Koordinaten: Erst kommen seine drei Positionswerte, danach die Ausdehnung in X-, Y- und Z-Richtung. Für eine Grundfläche hilft ein gedanklicher Test: Welche Kante soll dünn sein, welche beiden sollen den Spielbereich abdecken?

Viele GLOOP-Klassen teilen Methoden ihrer Oberklasse GLObjekt, zum Beispiel gibX(), gibY() und gibZ() für die Mittelpunktkoordinaten, sowie setzePosition(...), setzeFarbe(...) und loesche(). Die genaue Liste hängt von der jeweiligen Klasse ab.

Warum steht manchmal ein Punkt zwischen zwei Namen?

ball.verschiebe(...) bedeutet: Rufe die Methode am Objekt ball auf. Sys.warte() ist dagegen ein statischer Aufruf der Hilfsklasse Sys; dafür wird kein Sys-Objekt erzeugt.

Die PDF-Übersicht beschreibt GLOOP 3.7 und ist ausdrücklich keine vollständige Klassenreferenz. Nutze sie als Nachschlagewerk, nicht als Liste, die du auswendig lernen musst.

Wiedererkennen

So passen Java und GLOOP zusammen

GLKugel ball;
ball = new GLKugel(0, 0, 0, 20);

if (tastatur.links()) {
    ball.verschiebe(-1, 0, 0);
}
Sys.warte();
  1. GLKugel ball; benennt eine Variable und ihren Typ.
  2. new GLKugel(...) erzeugt ein Kugelobjekt; die Zuweisung speichert die Referenz darauf in ball.
  3. tastatur.links() fragt die linke Pfeiltaste ab und liefert wahr oder falsch.
  4. Wenn sie gedrückt ist, wird verschiebe auf der Kugel ball ausgeführt.
  5. Sys.warte() hält kurz an, damit die wiederholten Spielschritte sichtbar und steuerbar bleiben.

Wichtig: Wenn BlueJ GLOOP als unbekannt meldet, fehlen wahrscheinlich Projekt oder Bibliothek aus der schulischen Einrichtung. Entferne den Import nicht, um die Meldung zu verstecken.

Korrekturhinweise zur Syntax-PDF

  • Nicht jede Codezeile endet mit ;: Befehle meist schon, aber nicht die Kopfzeilen von if, while, Methoden oder Klassen.
  • Eine if-Anweisung führt ihren Block aus, wenn ihre Bedingung true ist.
  • String ist kein primitiver Datentyp. GLOOP-Klassen wie GLKugel sind ebenfalls Referenztypen.
  • Variablennamen müssen in ihrem Gültigkeitsbereich eindeutig sein; Namen dürfen in voneinander getrennten Methoden wiederverwendet werden.
  • = weist zu, == vergleicht. Das sind unterschiedliche Operatoren.

Diese Präzisierungen ersetzen die missverständlichen Kurzformulierungen in der PDF, nicht die im Unterricht vereinbarten Regeln.
